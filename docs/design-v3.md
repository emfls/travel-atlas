# Destination editorial redesign

The owner delegated routine visual decisions and authorized deployment to this existing GitHub Pages site. The direction is a destination-atlas editorial: oversized navy typography, warm paper, terracotta annotations, an illustrated landscape cover and six landscape-study cards. It differs from both the natural-history journal and botanical herbarium.

A generic recolor was rejected. A photo-led travel magazine would require verified licensed photographs, so the chosen artwork is original, explicitly abstract vector scenery rather than a reconstruction of real destinations. No new facts, rankings, bookings, prices, maps or live operational claims are added.
